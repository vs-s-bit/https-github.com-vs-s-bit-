# PATH Architecture

PATH is built as a student-first career navigation system.

## Runtime

- Mobile: Expo + React Native + TypeScript + Expo Router.
- API: Node.js + TypeScript + Express REST.
- Database: PostgreSQL + Prisma.
- Shared packages: types, validation, AI abstraction and database.

## Core rule

Structured career data is the source of truth. AI explains and personalizes that data; it does not invent official requirements, exam dates, vacancies or salaries.

## Next-step engine

The deterministic engine will inspect incomplete roadmap steps, prerequisites, weak skills, current progress and available study time. It returns one clear next action.

## Data verification

Government and other time-sensitive records must carry source, source URL, last verified date, next review date and verification status.

## Product principle

At every stage a student should know:
1. Where am I?
2. Where could I go?
3. What should I do next?
